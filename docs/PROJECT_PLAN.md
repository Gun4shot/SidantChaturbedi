# Project plan

## Creative objective

Build a vivid, hand-painted portfolio for Siddhant Chaturvedi that feels like travelling through an illustrated film. The site is a vertical journey rather than an open world. Generated key art carries the visual quality; browser animation adds depth, movement, and continuity.

## Current milestone

Create and validate the opening transition:

1. Begin above a mountain valley, with a restrained title and an animated flock.
2. Use scrolling to push the camera toward the valley.
3. Pass through layered cloud and motion washes that hide the image handoff.
4. Arrive at a matching riverbank landscape.
5. Reveal the About copy and a temporary illustrated character.

## Experience rules

- No persistent navigation over the opening artwork.
- Use generated or carefully sourced artwork for scenery; do not reconstruct scenery from primitive 3D models.
- Motion should feel cinematic but remain directly controlled by scrolling.
- Preserve readable HTML text and a reduced-motion path.
- Keep all tooling and assets within a zero-purchase budget.

## Next milestones

1. Replace the temporary character with a portrait based on approved photos.
2. Build a paper-theatre transition from About into Projects.
3. Create one illustrated diorama per flagship project using sourced project facts.
4. Add a compact end-of-page directory for direct access and accessibility.
5. Profile image loading, responsive crops, keyboard flow, and mobile performance.
